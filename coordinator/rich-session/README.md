## Implemented source

`decodeRichCarrier` accepts only primitive UTF8 JSON text, <=16384 bytes, exactly
six fixed keys/version/profile, safe original source UTC integer bounds and
canonical unpadded base64url of original Attributes/ContentState fragments.
The dedicated bounded strict parser rejects duplicate/escaped duplicate keys,
unknown closed fields, invalid UTF8/surrogates/BOM, nonfinite/bool numeric values,
unsafe counters and oversized/deep/token-heavy syntax. Parsed objects are owned
and deeply frozen; original strings and object spans retain escaping, Date
numbers, optional omission, key order and exact nested rich byte count.

The compiled nested shapes preserve current SessionSurfaceSnapshot and
PassiveActivityContent. Only their declared attribution dictionaries retain
the existing bounded string-map shape. Qualified display/source/relay rights
are NOT inferred from those strings or their usage labels. Attribution URLs
and now-playing source URLs are display metadata, never an image-fetch right.
Optional null aliases and unknown fields that Codable would silently omit are
not accepted as original encoder output. Empty-rich and oversized-rich
counterexamples are rejected. A neutral/minimal snapshot can remain DATA,
but the rich APNs DATA serializer refuses to manufacture a rich frame from it.

The original Apple fixture receipt497f7e34 and all34 inventory files are copied
byte-for-byte, including28 genuine existing CoreIOS encoder cases and explicit
inadmissible examples. Neither genuine encoding nor successful decoding makes
an original presentation/field/source/clock/native owner. The arbitrary String
Attributes example is valid String DATA, not a native identity acceptance.
Likewise a same-pin extended-deadline example can be structurally decodable:
`checkOriginalRichData` rejects changed original primitive bytes/bounds, while
actual per-field eligibility and mapping still require an independent owner.
No receivedAt/device-uptime equality with Core UTC is assumed or fabricated.

`projectOriginalUtcBoundsData` implements the selected exact conservative
ceil-observation/floor-expiry projection of a SUPPLIED original Core UTC
instant. It decomposes the exact IEEE754 value into a rational before multiplying
by1000; naive floating multiplication can cross an integer boundary. Independent
Python Fraction reference cases test that behavior. Empty/unsafe/negative bounds
reject. This helper creates no clock witness, Date conversion or original authority.
Foundation Date fields remain byte-unchanged and are never converted by it.

Three separate caps apply: original nested rich <=2800 UTF8bytes, original
Attributes+completeContentState <=4096, and actual final APNs JSON <=4096.
Exact equality is allowed and one byte over rejects. The reference update/end
serializer appends ONLY internally retained validated object fragments and
measures actual final output. It never reconstructs Foundation dates/escaping
through JSON.stringify. Supplied scalar event/dismissal timestamps are DATA,
not a verified current clock or permission to send an update/end. No truncation,
rewritten field lifetime, invented artwork or alternate status-only product exists.

Original fragment handles cannot be forged by copying a result object. Their
private WeakMap is a parser provenance fence, NOT a live permission capability.
All outputs explicitly remain DATA ONLY. The production factory always throws
before reading supplied owner/environment/namespace arguments. There is no
provider/fetch/key/SDK operation, registry mutation, live profile map, authenticated
permission wire or positive producer integration. The new profile ID deliberately
belongs to its own successor family; the old slash-version JsonObject API is not
silently made to accept it.

## Qualification and delivery

Dedicated strict types and actual workerd tests cover the original fixture
inventory, unknown/null/duplicate input, numeric/date/Unicode failures, exact
2800/4096 boundaries, complete update/end DATA, fragment preservation, immutable
outputs, original primitive checks, forged handles and exact UTC projection.
The standalone packaged ESM is tested independently on Node against its exact
module hash, original fixture hashes and UTC references. These checks do not
execute actual native lifecycle, read/artwork transport, provider or rights.

```sh
node_modules/.bin/tsc -p coordinator/rich-session/qualification/tsconfig.json --noEmit
node_modules/.bin/vitest run --config coordinator/rich-session/qualification/vitest.config.mts
node coordinator/rich-session/build-source.mjs "$TMPDIR/rich-profile-package"
node coordinator/rich-session/qualification/check-package.mjs "$TMPDIR/rich-profile-package"
```

Use new external Shared Data scratch locally. The locked source package records
all tracked inputs, installed esbuild hashes and the exact one-input graph; it
creates no Worker configuration or namespace. Own whole/exact independent review,
normal source/CI/protected/original delivery and separate Final remain required.
Actual original static attributes/ActivityID/target, independent source UTC bounds,
field/relay rights, native C0/boot/rate/restore/withdrawal and authenticated
permission/read/artwork composition remain separate required inputs. WidgetKit
invalidation does not prove host-app wake or Activity refresh, and calling a
plaintext API relay a background read cannot override external_relay:false.
